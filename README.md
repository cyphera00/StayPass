# StayPass — 기숙사 외박 신청 및 승인 관리 시스템

- 팀명: 집갈래요.
- 참가 분야: 학교생활 개선
- 프로젝트 종류: 웹 기반 시연용 프로토타입

## 1. 프로젝트 소개

StayPass는 기숙사 외박 신청 과정에서 발생하는 종이 서류 작성 및 보호자 문자 전달의 번거로움을 개선하기 위한 웹사이트입니다. 학생이 외박 일정을 입력하고, 보호자가 담임교사에게 보낼 문자 문구를 생성하며, 교사 화면에서 문자 수신 여부를 확인한 뒤 승인·반려하는 흐름을 시연할 수 있습니다.

## 2. 실행 방법

1. 압축파일을 내려받았다면 압축을 해제합니다.
2. `StayPass_v4_백업복원.html`을 Chrome 또는 Edge에서 엽니다(더블클릭).
3. `외박 신청` 메뉴에서 학번, 이름, 외박 시작·종료 시간, 사유를 입력하고 저장합니다.
4. `내 신청 내역`에서 `보호자 문자 보기·복사`를 눌러 생성된 내용을 확인합니다.
5. `교사 승인 대시보드`에서 해당 신청을 찾고, 보호자가 직접 보낸 문자를 실제로 확인했다고 가정한 후 `보호자 문자 수신 확인` → `최종 승인`을 눌러 시연합니다.
6. `내 신청 내역`에서 승인 상태가 변경되었는지 확인합니다.

**설치 및 실행 환경:** 별도 Python/Node.js 설치 없이 최신 웹 브라우저에서 실행할 수 있습니다. 인터넷 연결 없이도 기본 화면과 로컬 기능을 실행할 수 있습니다.

## 3. 주요 기능

- 학번·이름과 외박 날짜·시간·사유 입력
- 유효하지 않은 날짜 및 중복 외박 일정 검사
- 보호자에게 전달할 문자 문구 생성·복사(실제 발송 기능은 없음)
- 신청 내역 조회·수정·취소, 처리 기록 확인
- 교사 화면의 문자 확인·승인·반려 및 학번·이름 검색
- 날짜별 외박 현황 달력 및 CSV 내려받기
- JSON 파일로 신청 데이터 백업·복원

## 4. 사용 기술과 소스코드 구성

- **HTML**: 페이지와 입력 양식
- **CSS**: 화면 디자인 및 모바일 대응
- **JavaScript**: 입력값 검증, 신청 상태 변경, 조회 및 파일 백업·복원
- **localStorage**: 현재 브라우저의 신청 데이터 저장

`StayPass_v4_백업복원.html` 파일 하나에 HTML·CSS·JavaScript가 포함되어 있습니다. 별도 서버나 공용 데이터베이스는 사용하지 않습니다.

핵심 JavaScript 함수 예시: `validateLeave()`(외박 일시 검증), `overlaps()`(일정 중복 판단), `createRequest()`(신청 등록), `verifyParentSms()`(문자 확인 기록), `decide()`(승인·반려), `updateRequest()`(신청 수정).

## 5. 데이터 저장 및 초기화

- 신청 내역은 **접속한 브라우저의 localStorage**에 저장됩니다. 다른 기기로 자동 공유되지 않습니다.
- 상단의 `↓ 백업` 버튼으로 JSON 파일을 저장할 수 있습니다.
- 상단의 `↑ 복원` 버튼으로 백업 파일을 선택하면 현재 데이터를 교체하여 불러옵니다. **복원 전에 기존 데이터를 백업**하는 것을 권장합니다.
- 상단의 `↻ 초기화` 버튼을 누르면 현재 브라우저의 시연 데이터가 삭제됩니다.
- 브라우저의 저장소 차단·삭제 또는 HTML 파일 접근 경로 변경에 따라 저장 내용이 유지되지 않을 수 있습니다.

## 6. 제한 사항

이 프로젝트는 **대회 시연용 버전**입니다. 학생·교사 간 실제 로그인 인증이나 권한 통제가 구현되지 않았으며, 교사 메뉴는 누구나 시연할 수 있습니다. 보호자 문자 자동 전송/수신 확인, 학교 사이트(과구리) 연동, 서로 다른 기기 간 실시간 동기화는 지원하지 않습니다. 실제 학교 운영과 개인정보 처리에 사용하려면 서버, 인증, 권한 검사, 개인정보 보호 조치 및 학교의 승인이 필요합니다.

## 7. 검증 및 추가 테스트

핵심 JavaScript 로직에 대한 자동 테스트를 수행한 이력이 있습니다. 다만 **이 제출용 HTML 파일 자체에는 자동 테스트 실행 스크립트가 포함되어 있지 않습니다**. 제출 전 실제 브라우저에서 신청 → 문자 확인 → 승인, 일정 수정, 백업·복원을 다시 확인해야 합니다.

## 8. 출처 및 AI 활용

외부 라이브러리를 필수로 사용하지 않는 순수 HTML·CSS·JavaScript 웹사이트입니다. 설계·코드 작성·개선 및 문서 작성 과정에서 ChatGPT의 도움을 받았습니다. 실제 AI 활용 내역과 검증 과정은 별도 제출하는 `AI 활용 기록지`에 기재합니다.
